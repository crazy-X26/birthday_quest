# Birthday Quest

A little birthday quest to upgrade your age.
Solve the puzzles so your OS is up to date!

### 📎 Usage:
- 'npm run dev'       --> Live dev server
- 'npm run build'     --> Build project
- 'npm run preview'   --> Launch last build
